# 常见问题的回归检查

## 同步笔记与文件夹

外部同步来源的内容可能需要像本地内容一样管理。核对是否支持移动、重命名、删除、排序；来源更新应按既定覆盖规则保留人工编辑。至少检查：同步后移动文件夹、下次同步后移动仍保留、空文件夹、嵌套移动、循环父子关系、同时编辑和保存重试。不要直接编辑线上数据库文件来修复并发写入。树形拖动同时提供键盘或按钮移动入口；移动必须复核服务端所有权权限。

## Markdown、字体与导出

用 assets/markdown-fixture.md 对比预览和真实导出：标题、粗斜体组合、删除线、段落换行、嵌套列表、引用、代码、表格、任务列表、链接、图片及行内/块级公式。辨别 Markdown 解析、KaTeX 渲染、字体嵌入、PDF 排版哪一层丢失。LaTeX 命令支持范围取决于实际数学引擎，不能声称完整 TeX 支持；不支持语法要保留可读内容和明确提示。

字体须检查授权、真实字重/斜体文件、中文覆盖与公式专用字体；正文能显示中文不代表粗斜体有效。导出要看真实 PDF 的视觉和可检索文本，公式截图策略须说明文本不可检索的取舍。离屏 canvas/SVG 转换检查裁切和分页。

加速先测下载/字体处理/排版/保存各阶段；按需加载、字体缓存和可复用渲染可择优实现。不能用丢格式换速度。进度条按实际阶段更新，未知总量用不定进度，失败复位并保留原文，长任务允许取消时真正中止后续工作。

## 错误反馈

错误提示应留足阅读和操作时间，提供明显关闭键与可聚焦按钮；关键错误可持续显示到用户关闭。提供清晰的错误上报入口。收件人和主题从当前项目配置读取，正文只放已脱敏诊断；用 URL 编码并限制长度，超长时提供复制/下载备用。

打开默认邮箱只会创建草稿，不代表已发送。用户可检查后发送。日志删除令牌、Cookie、Authorization、密码、私钥、个人数据及敏感 URL 参数；不要自动采集整段聊天或数据库。mailto 不自动复制剪贴板；若要复制作为备用，明确按钮行为。无邮箱客户端时保留可复制内容。

## 功能停用与权限

按需求停用功能时，处理页面入口、直接访问地址、API 写入和搜索索引；按要求保留代码并记录恢复方法。只隐藏按钮不等于停用服务。停用支付入口前，确认新订单已关闭，并单独检查待处理订单与已有回调的处理方式。
